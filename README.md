# Hairouna Business Solutions

Production website rebuild for Hairouna Business Solutions.

## Direction
Premium, trustworthy Canadian tax and bookkeeping experience built around a restrained cinematic visual system: deep navy, silver, frosted glass and warm gold accents.

## Deployment
Target: Cloudflare Pages / Workers. GitHub is the source of truth. Replit is not part of this project.

## Safety
The existing live Hairouna website must remain untouched until the replacement build has been tested and explicitly cut over.

## Build principles
- Mobile-first and accessible
- Fast loading with progressive enhancement
- Respect `prefers-reduced-motion`
- SEO-friendly semantic content
- No fabricated testimonials, credentials, guarantees, tax outcomes, or security claims
- Preserve/integrate existing HB receptionist only after its production endpoint/API contract is verified
